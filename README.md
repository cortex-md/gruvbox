# Gruvbox for Cortex

The retro Gruvbox palette for Cortex, with dark (`bg0_h` #1d2021) and light (`bg0` #fbf1c7)
variants.

Install it from Cortex → Marketplace → Themes by searching for **Gruvbox**. For a manual install,
copy this directory to:

```text
<vault>/.cortex/themes/gruvbox
```

The manifest exposes one theme family named `gruvbox`. Cortex loads `dark.css` or `light.css`
according to the active color scheme.

## What it themes

- App surfaces, raised surfaces, quiet fills, hairlines and selection
- Text, accent, links and borders, with body text at WCAG AA contrast
- Status colors (error, success, warning) and the six heading colors
- All 13 callout types, tags and syntax highlighting
- Menus, dialogs, tooltips, sidebar, tabs, status bar, settings groups and workspace cards
- Shadows for floating panels, pills and primary buttons
- A monospace editor and code font

Sizes, radii and spacing follow the Cortex defaults, so the layout matches the built-in themes.
